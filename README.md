# 💬 Bubbly Chat App (MERN + Expo)

A modern **real-time chat application** built using **React Native (Expo)** with a powerful MERN backend. This app supports instant messaging, user authentication, profile updates, and media handling with a smooth mobile UI.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- 💬 Real-Time Messaging using Socket.io
- 👥 One-to-One Chat & Group Chat
- 🟢 Online/Offline Status
- 🖼️ Image Uploads via Cloudinary
- ✏️ Profile Update (Name, Avatar)
- ⚡ Fast & Responsive UI (React Native + Expo)

---

## 🛠️ Tech Stack

### Frontend
- React Native (Expo)
- Expo Router (File-based routing)

### Backend
- Node.js
- Express.js
- MongoDB (Database)

### Real-Time & Media
- Socket.io (Real-time communication)
- Cloudinary (Image storage)
